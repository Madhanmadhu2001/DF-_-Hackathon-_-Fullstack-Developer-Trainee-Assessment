A complete full-stack project built as part of the **DigitalFlake Job Hackathon 2025**.  
Includes a clean **React frontend**, a secure **Node.js backend** with JWT authentication,  
and a **MySQL database** using Sequelize ORM.

---

## 🌟 Features
### 🔐 Authentication
- Secure login  
- JWT-based authorization  
- Passwords hashed using bcrypt  

### 📦 Item Management (CRUD)
- Add new items  
- Edit existing items  
- Delete items  
- View item table with auto-refresh  

### 🎨 UI (React + Tailwind)
- Responsive dashboard  
- Clean form design  
- React Router v6 for navigation  

---

## 🛠️ Tech Stack
| Layer | Technology |
|-------|-------------|
| Frontend | React, Tailwind CSS, Axios, React Table |
| Backend | Node.js, Express.js, Sequelize ORM |
| Database | MySQL |
| Auth | JWT, bcrypt |

## ⚙️ Setup Instructions

### ▶ Backend
```bash
cd backend
npm install
cp .env.example .env
npm run dev
```

Database:
```sql
CREATE DATABASE df_hackathon_d;
```

### ▶ Frontend
```bash
cd frontend
npm install
cp .env.example .env
npm start
```
